 Uninformed Search Techniques

This project implements four Uninformed Search algorithms using python.

 Algorithms

 1. Breadth First Search (BFS)
Searches level by level.

Use Case: Finding the shortest route.

 2. Depth First Search (DFS)
Searches one path deeply before trying another path.

Use Case: Maze solving.

 3. Depth Limited Search (DLS)
Works like DFS but searches only up to a fixed depth.

Use Case: Game decision tree.

 4. Bidirectional Search
Searches from both the start and goal at the same time.

Use Case: Finding a route between two locations.
